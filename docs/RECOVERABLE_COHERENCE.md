  5. If recovery always leads to same → frozen, not living

## Implementation: Recovery Probe

### Core Primitive

```python
def recovery_probe(patch: Patch, perturbation: Perturbation) -> RecoveryResult:
    """
    Probe patch with perturbation
    Measure recovery quality
    
    Returns:
      - recovered: bool (did patch recover?)
      - recovery_time: float (how long to recover)
      - recovery_quality: float (how well recovered)
      - degradation: float (permanent damage?)
    """
    
    # Store initial state
    initial_compression = measure_compression(patch)
    
    # Apply perturbation
    patch.apply(perturbation)
    
    # Attempt recovery
    recovery_result = patch.attempt_recovery()
    
    # Measure recovery
    final_compression = measure_compression(patch)
    
    return RecoveryResult(
        recovered = recovery_result.success,
        recovery_time = recovery_result.time,
        recovery_quality = initial_compression / final_compression,
        degradation = max(0, initial_compression - final_compression)
    )
```

### Coherence from Recovery

```python
def coherence(patch: Patch, num_probes: int = 5) -> float:
    """
    Compute coherence C(z) from recovery capacity
    
    C = ability to preserve compressibility
        under structured perturbative continuation
    """
    
    total_recovery_quality = 0
    total_degradation = 0
    
    for i in range(num_probes):
        perturbation = generate_structured_perturbation(patch)
        result = recovery_probe(patch, perturbation)
        
        total_recovery_quality += result.recovery_quality
        total_degradation += result.degradation
    
    # Coherence = average recovery quality - accumulated damage
    avg_recovery = total_recovery_quality / num_probes
    avg_damage = total_degradation / num_probes
    
    C = avg_recovery * (1 - avg_damage)
    
    return C
```
