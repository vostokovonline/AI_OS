## Regime Stability

### When is a Regime Stable?

```
Stability S(z) = resistance to regime transition

S = high  →  regime is robust, perturbations stay within regime
S = low   →  regime is fragile, small changes cause transition
S = 0     →  singular, no stable continuation exists
```

### Stability Metrics

| Signal | Regime Implication |
|--------|-------------------|
| High prediction accuracy | Stable regime |
| Smooth transitions | Stable regime boundaries |
| Abrupt prediction failure | Regime transition |
| Conflicting predictions | Unstable regime overlap |
| Singular boundaries | Regime collapse |

## Regime Transitions

### When Do Transitions Occur?

```
Transition T occurs when:
  Continuation can no longer remain coherent within current regime
  Different regime offers coherent continuation
  Cost of transition < cost of forced coherence
```

### Transition Types

| Type | Continuation Effect |
|------|---------------------|
| **Smooth** | Gradual stability decrease, seamless transition |
| **Bifurcation** | Sharp regime split, incompatible continuations |
| **Phase transition** | Global restructuring of continuation space |
| **Collapse** | No stable continuation exists |
